AuraNet - Project Context

Overview

It is an IT engineering project The official title of the project is """AuraNet" Autonomous Self-Healing Zero Trust Architecture using eBPF and Federated Learning""

AuraNet is an autonomous, self-healing Zero Trust Architecture (ZTA) operating at the kernel level. It is built on Kubernetes, utilizes cryptographic identity (SPIFFE/SPIRE), and relies heavily on observability orchestrated through eBPF and Cilium. The Prject Also uses eBPF for runtime monitoring for achieveing zero trust.
