Detailed Description

Universal Hubble telemetry preprocessing pipeline.

Provides functionality for transforming raw Cilium Hubble network events into normalized numerical feature vectors suitable for Zero Trust Autoencoder training.

The dataset focuses on generalized behavioral features instead of application-specific identities.
