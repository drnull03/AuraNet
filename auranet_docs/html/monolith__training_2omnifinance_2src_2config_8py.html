Detailed Description

Central configuration module for the AuraNet Monolith Training Engine.

Defines paths, machine learning hyperparameters, model locations, and SOC inference thresholds used by the training and evaluation pipelines.

This module acts as the single source of truth for configurable parameters shared across training, testing, and inference components.
